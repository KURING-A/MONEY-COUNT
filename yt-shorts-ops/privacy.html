개인정보처리방침

시행일: 2026년 11월 16일 · 최종 수정: 2026년 11월 16일

YouTube Shorts Ops(이하 "본 도구")는 운영자 본인이 관리하는 YouTube 채널을 운영하기 위한 개인용 도구입니다. 본 방침은 본 도구가 Google 사용자 데이터에 어떻게 접근하고, 사용하고, 저장하는지를 설명합니다.

1. 접근하는 데이터

구분내용목적
채널 정보채널 ID, 채널 이름 등 공개 채널 정보어느 채널에 작업할지 식별
동영상 정보본인 채널의 동영상 메타데이터(제목, 설명, 태그, 공개 상태)업로드 및 메타데이터 관리
통계 정보본인 채널의 조회수, 시청 시간, 시청률 등 YouTube Analytics 데이터채널 성과 확인

본 도구는 시청자의 개인 식별 정보, 댓글 작성자의 신원 정보, 제3자 채널의 데이터에는 접근하지 않습니다.

2. 데이터의 저장과 처리 위치

  • Google 계정 인증에 사용하는 OAuth 2.0 갱신 토큰(refresh token)은 운영자 본인의 기기 안에만 저장됩니다.
  • 토큰은 운영자 외에는 접근할 수 없도록 파일 권한이 제한되어 저장됩니다.
  • YouTube에서 조회한 데이터는 운영자의 기기에서 처리되며, 운영자가 별도로 운영하는 외부 서버로 전송되거나 보관되지 않습니다.

3. 데이터의 이용 목적

접근한 데이터는 오직 본인 채널의 영상 업로드, 메타데이터 관리, 성과 확인 목적으로만 사용합니다.

4. 제3자 제공 및 판매

  • 본 도구는 Google 사용자 데이터를 제3자에게 판매하지 않습니다.
  • 광고, 프로파일링, 대출 판단, 감시 목적으로 사용하거나 이전하지 않습니다.
  • Google 사용자 데이터를 인공지능 모델의 학습 데이터로 사용하지 않습니다.

5. 보관 기간과 삭제

  • 데이터는 위 목적을 수행하는 동안에만 보관되며, 필요가 없어지면 삭제합니다.
  • 운영자가 저장된 토큰 파일을 삭제하면 즉시 접근이 중단되고 보관 정보도 함께 삭제됩니다.
  • 언제든지 Google 계정의 보안 설정에서 본 도구의 접근 권한을 직접 취소할 수 있습니다. 권한 취소 후에는 본 도구가 해당 계정의 데이터에 접근할 수 없습니다.

6. 보안

인증 정보는 운영자 기기 내에만 보관하며, 전송 구간은 HTTPS로 보호됩니다. 인증 정보는 문서, 채팅, 보고서 등 외부에 노출되지 않도록 관리합니다.

7. 아동

본 도구는 아동을 대상으로 하지 않으며, 아동의 개인 정보를 수집하지 않습니다.

8. Google API 서비스 정책 준수

본 도구는 Google API 서비스 사용자 데이터 정책을 포함한 Google API 서비스 약관을 준수합니다.
