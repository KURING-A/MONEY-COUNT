# 🏢 태영 님 비서실 · 탱구 본부

태영 님 전용 모바일 비서실 웹앱(PWA)입니다. 폰에서 열고 **홈 화면에 추가**하면 앱처럼 뜹니다.

- 지금 주소: https://kuring-a.github.io/MONEY-COUNT/taenggu-office/ (KURING-A/MONEY-COUNT 저장소의 Pages 아래)
- 옮길 곳: `KURING-A/taenggu-office` 공개 저장소를 만들면 이 폴더 내용을 그대로 올려 `https://kuring-a.github.io/taenggu-office/`로 쓸 수 있습니다.
- 구성: 🗺️ 오피스 맵 · 💬 회의실 · 📋 작업실 · 📊 비서현황 · 📝 메모
- 오피스 맵 이미지는 `images`(AI 생성)로 만든 클레이 스타일 3D 미니어처입니다.

## 안에 들어 있는 것

| 탭 | 내용 |
| --- | --- |
| 오피스 맵 | 클레이/기본 지도 토글, 움직임 토글, 7개 파트 배지 → 탭하면 최신 현황 시트 |
| 회의실 | 대회의실·지휘실·라운지 대화 로그, @멘션과 입력, localStorage 저장 + 자동 응답(시뮬레이션) |
| 작업실 | 실제 정기 루틴 12개 카드와 다음 실행 시각(폰 시계 기준 계산) |
| 비서현황 | 9채널 48h 실측, 주간 목표 진척, 채널별 표, 지속률, 가동 상태 |
| 메모 | 태영 님이 직접 처리할 일 체크리스트, 최근 확정 규칙 요약, 메모 추가/삭제 |

## 파일

- `index.html` — 앱 전체(스타일·스크립트 포함, 단일 파일)
- `office-clay.webp` / `office-basic.webp` — 오피스 맵 이미지
- `manifest.webmanifest`, `sw.js`, 아이콘들 — PWA(홈 화면 추가·오프라인)

## 개인정보

공개 저장소입니다. 이름은 "태영 님"으로만 표기하고, 실명·주소·전화번호·계정·비밀번호·토큰은 담지 않았습니다.
화면의 대화와 메모는 서버가 아니라 **보는 사람의 브라우저 localStorage**에만 저장됩니다.
